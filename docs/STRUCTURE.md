# Project structure / Estrutura do projeto

## English

| Path | Purpose |
|------|---------|
| `src/main.tsx` | App bootstrap |
| `src/App.tsx` | Root component |
| `src/components/` | Reusable UI components |
| `src/hooks/` | Custom React hooks |
| `src/styles/` | Global CSS / CSS modules |
| `public/` | Static assets |
| `vite.config.ts` | Vite config (aliases, plugins) |

Keep components small; colocate tests next to the file (`Component.test.tsx`).

## Português

| Caminho | Objetivo |
|---------|----------|
| `src/main.tsx` | Bootstrap da app |
| `src/App.tsx` | Componente raiz |
| `src/components/` | Componentes UI reutilizáveis |
| `src/hooks/` | Hooks React personalizados |
| `src/styles/` | CSS global / CSS modules |
| `public/` | Assets estáticos |
| `vite.config.ts` | Config Vite (aliases, plugins) |

Mantém componentes pequenos; coloca testes junto ao ficheiro (`Component.test.tsx`).
